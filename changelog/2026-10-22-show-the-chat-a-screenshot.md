The project chat now takes images: paste, drop or pick a screenshot to show what you mean. Use @ or the context picker to point it at an analysis, a user story or a test.

When the chat proposes a change to your context, flows or tests, it arrives as a card you can apply, edit or discard, and an applied change can be reverted. Reviewing a change to tests opens a readable preview of each test, with changed fields and added or removed steps highlighted, and a JSON diff one click away.

You can keep typing while Wopee.io answers; only sending waits for the reply.
