title: "Answer the agent in one click, or let it go on"
description: "An agent question now shows one recommended option and a two-minute countdown; with no answer the run continues with that option and the chat says so."
---

When the agent asks you something during a run, the question card marks one recommended option and counts down the two minutes the agent waits. Pick an option with a click or with its number key.

If nobody answers, the options lock, the run continues with the recommended option, and the chat notes "No answer, continued with" that choice. The run report lists every question asked and how it was answered.
