title: "A test that never ran opens on its steps"
description: "Select a test that has not run yet and its steps open instead of an empty run view; story names show in the scope picker and step lists indent cleanly."
---

In the analysis workspace, selecting a test that has never run now opens its Steps instead of a Run view that only says there are no runs yet. A test with runs still opens on its latest run, or on Live while it is running.

In the Generate scenarios picker, a user story without a name is labelled by its category instead of a bare ID. Numbered and bulleted lists in a scenario description on the Steps tab are indented, so their markers stay inside the panel.
