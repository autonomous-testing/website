title: "Test data that changes on every run"
description: "AI-generated variables now produce a fresh value per run, and the faker catalog adds IBAN, alphanumeric strings, usernames, and Czech birth numbers."
---

AI-generated test variables now produce a different value on every run, so repeated runs stop reusing the same email or name. The built-in faker catalog also grew: IBAN, alphanumeric string, username, and Czech birth number generators are now selectable in the variables dropdown, alongside static values, lists, and AI prompts.
