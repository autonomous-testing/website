title: "Your first analysis ends with tests already run"
description: "Scenarios generated during a crawl now start running automatically, so a fresh analysis ends with real results instead of a board of not-run cards."
---

Until now, a finished crawl left you with generated scenarios and a Run button. Now the agent queues scenarios the moment they are generated, while the crawl is still exploring, and runs them automatically as real runs with reports, history, and retry. Point Wopee.io at a URL, come back, and the first results are already waiting.
