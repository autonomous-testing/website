title: "The chat asks before it replaces your tests"
description: "Asking the chat to generate tests now updates your suite; anything that would replace existing tests or steps waits until a project admin confirms it."
---

Asking the chat to generate tests now updates your existing suite instead of starting it over. A request that would replace work, such as creating test cases from scratch, rebuilding the outline or regenerating test steps, no longer starts on its own.

The chat posts a card that says what the run would do and what it would replace. A project admin can confirm and run it or discard it; anyone else is asked to get an admin. Every open chat shows the same state, and a confirmed request links straight to the analysis.
