slug: unified-run-logs
title: "One Logs tab for every run"
description: "Run logs now stream live under a single Logs tab for all runs, including pre-warmed pooled agents, with the GitHub Actions deep link where it belongs."
---

Every run now has a Logs tab that streams the agent log live, with tail-follow while the run executes. That includes pre-warmed pooled runs, where logs used to be unavailable. The GitHub Actions deep link moved into the same tab, so raw CI output and agent logs live in one place.
