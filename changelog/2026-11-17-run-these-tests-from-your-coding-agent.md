When an analysis finishes with tests to run, project admins see a card in the analysis: Run these tests from your coding agent. Copy setup prompt gives you one line, with your project filled in, to paste into Claude Code or another coding agent. The card then follows the setup: key created, connected from your agent, first test run.

The same prompt is in Project Settings under API Keys, next to the environment variables, and in the dialog that creates a key.
