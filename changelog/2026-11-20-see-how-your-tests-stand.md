---

The Scenarios table now starts with a results summary for the tests it shows: passed, failed, incomplete and not run, a verdict bar, the pass rate and the last run. Click a count to filter the table by it. The Status column, its filter and its grouping use the same verdicts.

A new Overview view adds a chart of the latest verdicts, the pass rate over the last 7, 14 or 30 days, and a By tester table with who started each test's latest run. Every tile, slice and number opens the table filtered to those tests.

Creating a test with a name another scenario in the project already uses now asks first. Create anyway keeps it, and Cancel takes you back with your draft as it was.
