Asking the chat to add a test used to stop when no user story in the analysis fit it. The chat now proposes the missing story together with the test case, as one change you review and apply like any other.

The chat also no longer sees the values of your secret project variables. Passwords, tokens and keys appear to it as `***`, while your runs still get the real values.
